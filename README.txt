Print Selector
==============

Print Selector is a lightweight, portable desktop utility for multi-tray
printers on Windows. It gives you per-page tray routing, saved tray
templates, batch printing, and carbon copy mode without going through
the standard Windows print dialog.

No installer or external runtime is required. Copy "Print Selector.exe"
anywhere and run it directly.


What It Does
------------
* Per-page tray routing
    Assign individual pages of a document to specific paper trays
    (Tray 1-4, MP Tray, or Auto Select). Useful when mixing letterheads,
    plain paper, coloured stock, or pre-printed forms in a single print job.

* Carbon copy mode
    For single-page documents, print the same page once from each selected
    tray in a single job. Ideal for multi-part forms or colour-coded copies.

* Batch printing
    Drag and drop multiple files onto the window to print them in sequence
    using the currently selected tray template.

* Saved templates
    Save recurring tray sequences under a custom name (e.g. "Invoice",
    "Letterhead") so repeat jobs can be applied in one click.

* Broad file format support
    - PDF (.pdf)
    - Word, OpenDocument Text, Rich Text, Plain Text (.docx, .doc, .odt, .rtf, .txt)
    - Excel, OpenDocument Spreadsheet, CSV (.xlsx, .xls, .ods, .csv)
    - PowerPoint, OpenDocument Presentation (.pptx, .ppt, .odp)
    - Images (.jpg, .jpeg, .png, .bmp, .tiff, .tif)

    PDFs and images are handled natively by Windows. Office documents are
    converted automatically in the background using the locally installed
    Microsoft Office applications (Word, Excel, PowerPoint).

* Print overrides
    Override colour/monochrome output, portrait/landscape orientation,
    page ranges (e.g. "1-3, 5"), copy count, and reverse page order.

* Page preview
    Click any page thumbnail in the assignment list to inspect a larger
    scrollable preview of that page.

* Multi-language interface
    Supports English, German, French, Italian, Spanish, and Japanese.
    Your selected language and saved templates are stored automatically.

* Automatic crash logging
    If an unexpected error occurs during document conversion or printing,
    a timestamped report is written to the LOGS folder next to the executable
    (or %APPDATA%\Print Selector\LOGS if the folder is read-only).


System Requirements
-------------------
* Windows 10 or Windows 11 (uses the built-in .NET Framework 4.8 and
  Windows.Data.Pdf rendering engine included with the OS)
* Microsoft Office (only required when opening Word, Excel, or PowerPoint
  files; PDF and image printing require no additional software)
* At least one installed local or network printer
